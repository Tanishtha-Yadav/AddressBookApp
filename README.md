# AddressBookApp - UC18: Retrieve Contacts by Period

## Overview
UC18 extends the AddressBook System by **retrieving contacts added within a specific date range** using JDBC.  
- Introduces **date_added** field in the database table  
- Uses **PreparedStatement** for safe retrieval  
- Supports **JUnit tests for verifying correct retrieval**

---

## Notes

- UC18 continues **TDD approach**  
- Works with any **JDBC-supported database**  
- Future UCs may include **advanced filtering, sorting, or reporting**
